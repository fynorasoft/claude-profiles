# Claude Profiles

Run multiple Claude Desktop accounts side by side on your Mac. Each profile opens the Claude Desktop app you installed from Anthropic with its own sign-in, chats and settings.

This repository hosts **release downloads and the update feed** for Claude Profiles. The source code is private.

## Download

[Download the latest version for Mac](https://github.com/fynorasoft/claude-profiles/releases/latest/download/ClaudeProfiles.dmg) · macOS 15 or later · Apple Silicon and Intel

The app is signed and notarized by Apple and updates itself.
